分数怎么读

0–100 是位次分：约等于在该基准的当期模型池里赢过多少比例的对手——相对站位，不是考试分。维度分 = 该维各计分基准族位次分的加权均值，权重按族内模型数分级 w(n)=min(1,(n−1)/3)（×1.0 / ×0.67 / ×0.33）。

同一基准跨来源只算一票；族内仅 1 个模型的基准不计分（单模型无对手）。

缺数据 ≠ 0 分

缺计分证据的维度：雷达断开、条形留「待定」、综合分该维权重让位。低置信（族内 2–3 人）证据按 ×0.67 / ×0.33 降权参与。

标记得分

† = 该维仅由 1 个基准族支撑（单一来源 ≠ 模型弱）；·低覆盖 = 本场景权重覆盖不足 60%，名次仅供参考；虚线值 = 推理补全（估算，非实测，默认口径不计入）。

排名的置信带（±）

分数旁的 ±x 是置信带：证据支撑越弱（覆盖维少、基准族内对手少），带越宽。它由各计分基准族的可比对手数推算——权重 w(n)=(n−1)/3 本质是置信度权重（话语权 ∝ 可比对手数），不是价值偏好。

≈并列判定：两模型差距落在置信阈内就不分胜负——全支撑模型沿用「差 <2 分 ≈平」，支撑弱的自动放宽。榜单里的「≈ 并列」分隔条表示：以上几名在统计上分不出高下（不是没有差别，是证据还不足以分出差别）。
