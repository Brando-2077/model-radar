模型雷达

分数怎么读

0–100 是位次分：约等于在该基准的当期模型池里赢过多少比例的对手——相对站位，不是考试分。维度分 = 该维各计分基准族位次分的加权均值，权重按族内模型数分级 w(n)=min(1,(n−1)/3)（×1.0 / ×0.67 / ×0.33）。

同一基准跨来源只算一票；族内仅 1 个模型的基准不计分（单模型无对手）。

缺数据 ≠ 0 分

缺计分证据的维度：雷达断开、条形留「待定」、综合分该维权重让位——不按 0 惩罚。低置信（族内 2–3 人）证据按 ×0.67 / ×0.33 降权参与。

标记得分

† = 该维仅由 1 个基准族支撑（单一来源 ≠ 模型弱）；·低覆盖 = 本场景权重覆盖不足 60%，名次仅供参考；虚线值 = 推理补全（估算，非实测，默认口径不计入）。
