## 1. 这份数据是什么

「模型雷达图」是一个**按场景选模型**的决策工具：把公开榜单的分数归一化到 **8 个能力维度**，按 **5 套场景权重**加权，得到每个模型在每个场景下的加权综合分与全池名次。

同一份数据与算法（本文档所述全部内容）同时驱动两个独立分发的产品：

| 产品 | 形态 | 与本数据包的关系 |
|---|---|---|
| GitHub 网页版 `model-radar.html` | 桌面优先单文件网页 | 消费本数据 |
| 小红书工具版 `model-radar-xhs.zip` | 手机竖屏离线小工具 | 消费同一份数据 |

**两个版本的 UI、交互、功能完全独立；唯一共享的就是本文档描述的「数据 + 算法 + 口径」。** 因此，基于本包重新设计任何页面模板，都是在替换 UI 层——数据语义与计分口径必须原样继承。

当前规模：**33 个模型（全部有计分证据）· 722 条证据（实测 709 + 推理补全 13）· 686 条计分证据 · 55 个计分基准族 · 覆盖 247/264 个（模型×维度）格**。

## 2. 计分方法（完整口径）

### 2.1 总览：两步计分

```
原始分（各公开榜单，量纲各异）
   │  ① 量纲归一化：统一折到 0-100（只是「面值」可读化，不改名次）
   ▼
同（来源×类别）池内的 0-100 面值
   │  ② 基准族内位次分：同一基准族内，算「赢过多少比例对手」
   ▼
族内位次分（全站唯一分值口径，0-100）
   │  ③ 同一（模型×族）只留一票 → 族加权均值 = 维度分
   │  ④ 维度分按场景权重加权 = 场景综合分
   ▼
8 个维度分 + 5 套场景综合分（每个模型）
```

**核心思想：跨基准的面值不可比**（不同基准难度、量纲、harness 都不同），直接平均会被「高面值低名次」的证据带偏。位次分把所有证据统一到同一个问题：*在该基准的当期模型池里，这个模型赢过了多少比例的对手？*

### 2.2 第一步：量纲归一化（面值 → 0-100）

| 原始量纲 | 规则 |
|---|---|
| 0-100 / 百分制 | 原值直用 |
| 0-1 | ×100 |
| 10 分制 | ×10 |
| 5 分制 | ×20 |
| Elo / 指数 | 同（来源，类别）池内 min-max 线性映射到 60~100 |

Elo/指数的 min-max **不改名次**，只把面值拉进可读区间（第二步只看名次）。

### 2.3 第二步：基准族内位次分（全站唯一口径）

先按「数据来源 × 榜单类别」把证据归入**基准族**（例如 AA 的 GPQA、LiveBench 的 Coding、SuperCLUE 的 Writing 总榜各是一个族；同族 = 同一个基准、可直接排名）。

$$\text{位次分} = \frac{\text{族内升序名次} - 0.5}{n} \times 100$$

- **升序名次**：分数最低记第 1 名。因此族内最强者约 97 分、垫底约 3 分。
- **语义**：位次分 = 该模型在该基准的当期模型池里「赢过的对手比例」。
- **tie 处理**：同分取名次均值（如两人并列第 3，各记 3.5）。
- **n = 族内参与排名的模型数**（不是证据条数）。

⚠️ **位次分是池内相对分**：增减任何一个模型，全池所有同族证据的位次分都会整体移动。这是有意取舍（不是 bug）——跨期看图只比相对位次，不比绝对值。

### 2.4 去重规则（同一基准只算一票）

- **同（模型×基准族）多来源证据只留一票**：第三方来源优先；来源同级时数据日期新者优先。被淘汰的行不进账本（原始表中留档可溯源）。
- **Terminal-Bench 特例**（AA 渠道）：AA 同时报 2.1 与 4.0 两个版本、难度差异大，同一模型**有 4.0 用 4.0，缺则回退 2.1**，两版不重复计分。
- 厂商自报与第三方对同一基准都有分时，第三方胜出（见 2.7 的口径开关）。

### 2.5 族权重与维度分（v0.26「分级入分」）

维度分 = 该维**全部计分行**位次分的**加权均值**，权重由族内人数决定：

$$w(n) = \min\left(1,\ \frac{n-1}{3}\right)\quad\text{（保留 2 位小数）}$$

| 族内人数 n | 权重 w | 含义 |
|---|---|---|
| n = 1 | 0（不计分） | 单模型无对手，位次分恒 50、零信息量；行保留面值可查 |
| n = 2 | 0.33 | 低置信证据，降权参与 |
| n = 3 | 0.67 | 低置信证据，降权参与 |
| n ≥ 4 | 1.0 | 满权 |

- 设计逻辑：**话语权 ∝ 可比对手数**——3 个对手（族内 4 人）为满权。
- 当前 686 条计分证据中 23 条为低置信降权（n=2/3），其余满权。
- 某维的计分行只来自 **1 个基准族**时，该维打「**单基准 †**」标记（`sf` 字段）——单一来源支撑的维度不是全貌，UI 上应可辨识（如 † 上标 + 悬停说明）。

### 2.6 场景综合分与名次

$$\text{场景综合分} = \frac{\sum_{d \in \text{有分维}} W_d \times \text{维度分}_d}{\sum_{d \in \text{有分维}} W_d}$$

- **缺维让权**：只对该维有分的维度求和。缺数据的维度**绝不按 0 计**，而是把它的权重让给有分的维度（分母同步收缩）。这是红线，见 §6。
- **全池名次** = 1 + 综合分严格更高的模型数（**同分并列高位次**）。名次只在「该场景下至少有一维有分」的模型中计算。
- 维度名次同理：1 + 该维分数严格更高的模型数。
- 展示层建议：综合分显示 1 位小数；**名次按全精度计算**（例如第 1/2 名显示可能同为 83.2，但名次由全精度差决定）。

### 2.7 三档数据口径

位次分按全池**只算一次**；三档口径只决定**哪些证据进入维度均值**：

| 口径 | 进入均值的证据 | 说明 |
|---|---|---|
| **全部来源**（默认） | 全部实测计分行 | 含厂商自报 |
| **仅第三方榜单** | 实测计分行 − 厂商自报渠道 | 整体剔除以下 7 个渠道：`Z.ai官方 / dots官方 / 腾讯官方 / NVIDIA官方 / DeepSeek官方 / 酥悠沫-官方 / Kimi官方`。**按渠道排除，不按「是不是自家模型」**（NVIDIA 官方页给别家模型报的分也排除）。只被厂商自报覆盖的维度落「待定」（权重让位），不是 0 |
| **含推理补全** | 全部来源 + 对无实测的格补推理值 | 推理值（13 条）默认**不进**维度分；仅本口径下，无实测的格子用推理值显示（UI 上须与实测可区分） |

推理补全有两种方法（每条都带方法/依据/留一误差，`method/basis/loeoMAE` 字段）：M1 同族前版直推、M2 池内 k 近邻（Pearson 剖面相似度，k=5，留一 MAE 21.5 位次分）。

**本包导出的前 10 模型按默认口径「全部来源」**；JSON 中 `scoresTp`（仅第三方）与 `scoresInf`（含推理补全）只在和默认口径不同时提供。

### 2.8 可选展示层公式：置信带（小红书版现行，主版未用）

给综合分加 ±σ 置信带，衡量证据支撑强度（借鉴 Arena / HELM 实践，可选用）：

- 维度级：`σ_d = clamp(35/√(1+m_d), 5, 32)`，其中 `m_d = Σ(该模型该维各计分族 w(n)·(n−1))`；缺维或仅推理值时按先验 30。
- 场景级：`σ_scene = √(Σ(W_d·σ_d)²) / ΣW`。
- ≈平判定：两模型差距 ≤ `2·√(σa·σb)/σref` 时标「≈平、不判胜负」，`σref` = 该口径满覆盖模型场景 σ 的中位数。支撑弱时判平阈值自动放宽。

## 7. 数据使用须知（语义红线，新 UI 必须继承）

1. **缺数据 ≠ 0**。缺计分证据的维度不参与任何绘制与加权：雷达图断开（不连圆心、轴端画空心虚线圈）、条形图留「待定」空位、综合分该维权重让位。任何「把缺失画成 0 / 让多边形塌向圆心」的画法都是错误。
2. **所有分数都是 33 模型全池的相对位次**，不是绝对刻度。页脚/图注应保留位次口径说明；「#N」徽章的分母是全池（如 #4/33 的语义是全池第 4），只展示前 10 不改变这一点。
3. **单基准 † 维度不是全貌**：该维只由 1 个基准族支撑，凹坑可能只是「单来源」而非模型弱（典型：Opus 的指令遵循 38.2、Astra 的长文本 48.3）。UI 应保留 † 标识与解释文案。
4. **低置信证据已降权但仍在分里**（n=2/3 族，w=0.33/0.67）。若 UI 展示证据明细，应显示族内人数与权重，让「这条证据有多可信」可读。
5. **推理值与实测必须可区分**（虚线/斜纹/角标），且默认口径下推理值根本不参与计分。
6. **厂商自报口径**：三档口径开关的语义按渠道整体排除，不是按模型排除；切换口径时前端**只换数据、不重算分**（重算发生在数据管线侧）。
7. **同分并列**：名次并列取高位次；两模型综合分差距小于 ~2 分时不宜下「明显更强」的结论（可选：用 §2.8 置信带公式做 ≈平判定）。
8. **视觉自由，语义不自由**：配色、字体、构图、布局完全交给新设计；以上 1–7 是数据语义，任何 UI 不得违反。
