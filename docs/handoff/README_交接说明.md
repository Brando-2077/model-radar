## 2. 三句话理解这个项目

1. 把公开榜单分归一化成 **8 个能力维度**的「族内位次分」（在该基准的模型池里赢过多少对手），按 **5 套场景权重**加权——帮人按场景选模型。
2. 所有分数是 **33 模型全池的相对值**；缺数据的维度**让权而不是当 0**。
3. 本包只含前 10 名模型的数据（默认口径「自媒体内容运营 × 全部来源」下的前十），但**名次分母仍是 33**；切场景的前十名单会变（完整榜在 JSON 里）。
