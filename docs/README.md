## 推荐阅读顺序

1. 先看根目录 [README](../README.md) 的“为什么做这个项目”和“数据口径”；
2. 想引用分数 → [方法论](methodology.md) + [数据来源](data-sources.md)；
3. 想提数据纠错 → [FAQ 的“纠错与贡献”](faq.md#纠错与贡献)；
4. 想加模型 → [加模型指南](adding-models.md)；
5. 想改代码 → [架构与数据流](architecture.md)。

## 一句话版本

> 分数是**当期模型池内的相对位次**，不是绝对能力值；缺数据是“待定”，不是 0；厂商自报可以一键排除；每条证据都能回到来源。
